# expense-tracker-mariababy
A simple Expense Tracker web application built using HTML, CSS, and JavaScript. Users can add, edit, delete, search, and filter income and expenses.

## Features

- Add income and expense transactions
- Add description, category, date, and amount
- Edit and delete transactions
- View total income, total expenses, and balance
- Search transactions
- Filter transactions by type and category
- Monthly expense reports
- Category-wise monthly expense chart
- Data stored using browser Local Storage
- Responsive design for desktop and mobile

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

- Option 1 : Directly double click on the index.html
- Option 2 :- Open the project in vs code, use live server or go to Run -> Start Debugging/ Run Without Debugging
